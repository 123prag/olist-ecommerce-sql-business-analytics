# Power BI dashboard plan

Connect Power BI to PostgreSQL and build five sections:

1. Executive: revenue, orders, customers, AOV, late-delivery rate, avg review score.
2. Revenue trend: monthly revenue, orders and growth.
3. Customers: one-time vs repeat, RFM segments, cohort retention.
4. Products/Sellers: top categories, top sellers, concentration.
5. Delivery/Reviews: late rate by state, review score by timeliness.

Use a clean layout and keep each page focused on 3–5 decisions.
